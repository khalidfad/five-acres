Five Acres Ltd website

Deploy: upload this folder to Vercel (Framework preset: Other; no build command; output directory blank).
Form: submits through formsubmit.co to fadelemichael2@gmail.com. After deploying, send one test enquiry and click the activation link FormSubmit emails to that inbox (check spam).
Search: submit https://fiveacresng.com/sitemap.xml in Google Search Console.
Edit IMG/CFG at the top of assets/app.js to change photos, CEO portrait (IMG.ceo) and form settings.
